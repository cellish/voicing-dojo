# ボイシング道場（Voicing Dojo）

上から降りてくるコードを判定ラインで鍵盤で弾き、コード進行のボイシング（押さえ方）と声部のつながりを
全12キーで練習するブラウザ用アプリ。

- 12キー制覇コース（全29ステップ）：3和音 → ガイドトーン → シェル → 4和音 → 5和音ルートレス → ジャズの定番進行。キーの順番は五度圏順・半音ずつ・ランダムから選べる
- フリー練習：進行・キー・難易度・ボイシング・テンポ・表示時間・耳コピ（コード名を隠す）を選んで練習
- チャレンジ：今日のドリル（日替わり）、スピードアップ（キーごとに BPM +5、ミスで終了）、耳コピ、苦手キー克服。バッジと連続練習日数
- 自己ベスト・ランク（S/A/B/C）・コンボ
- ヒント：構成音の音名と、次に弾く鍵を色で示す鍵盤ヒント（どちらも ON/OFF できる）
- 入力：MIDI 鍵盤、画面の鍵盤（マルチタッチ）、PC のキーボード（A〜L）

## 使い方

公開ページ：https://cellish.github.io/voicing-dojo/

ビルドは不要です。`index.html` をブラウザ（Chrome、Safari）で開けば動きます。
Safari（iPhone・iPad を含む）は Web MIDI に対応していないため、MIDI 鍵盤は使えません。画面の鍵盤と PC のキーボードで弾けます。
音の再生に Tone.js をインターネットから読み込むので、オンラインで使ってください。

## ファイル構成

- `index.html`：アプリ全体（画面・スタイル・プログラム）
- `STATUS.md`、`PLAN.md`：現状、未完了の作業
- `docs/DESIGN.md`：設計の決定
- `docs/INVENTORY.md`：中身の一覧（道場シリーズの共通部品の検討用）
- `LICENSE`：著作権表示
- `THIRD_PARTY_NOTICES.md`：利用している他者の著作物（ソフトウェア・収録進行）
- `test/`：自動テスト（`node --test` で実行。ブラウザ部分をスタブにして通しプレイなどを確かめる）
