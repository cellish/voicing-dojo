# ボイシング道場（Voicing Dojo）

上から降りてくるコードを判定ラインで鍵盤で弾き、コード進行のボイシング（押さえ方）と声部のつながりを
全12キーで練習するブラウザ用アプリ。

- 12キー制覇コース（全13ステップ）：3和音 → ガイドトーン → 4和音 → 5和音ルートレス
- フリー練習：進行・キー・難易度・ボイシング・テンポ・表示時間・耳コピ（コード名を隠す）を選んで練習
- 入力：MIDI 鍵盤、画面の鍵盤（マルチタッチ）、PC のキーボード（A〜L）

## 使い方

ビルドは不要です。`index.html` をブラウザ（Chrome、Safari）で開けば動きます。
音の再生に Tone.js をインターネットから読み込むので、オンラインで使ってください。

## ファイル構成

- `index.html`：アプリ全体（画面・スタイル・プログラム）
- `PROGRESS.md`：作業の記録と引き継ぎ
- `docs/PLAN.md`：設計と計画
- `docs/INVENTORY.md`：中身の一覧（道場シリーズの共通部品の検討用）
- `LICENSE`：著作権表示
- `THIRD_PARTY_NOTICES.md`：利用している他者のソフトウェア
